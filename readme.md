# SmartFactory

SmartFactory is a data analytics project that helps manufacturing companies identify early signs of production quality issues by combining machine uptime logs, maintenance reports, and defect records into a single dashboard.

## Problem Statement

A manufacturing company logs machine uptime, maintenance reports, and defect records separately, preventing operations teams from identifying early signals that precede production quality failures.

## Objective

The goal of this project is to:

- Combine manufacturing datasets into one system.
- Analyze relationships between machine performance and product defects.
- Visualize important insights through an interactive dashboard.
- Help operations teams make proactive maintenance decisions.
